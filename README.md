# HAPTIC-NAVIGATION-SOFTWARE-SYSTEM
It is a software navigating system with which visual impaired people can able to travel from Point A to Point B by detecting obstacles.
A **Haptic Navigation Software System** based on a webcam is designed to detect obstacles in real time using computer vision, without requiring additional sensors such as ultrasonic sensors or LiDAR. The system captures live video through a standard webcam and processes each frame using image processing and deep learning algorithms to identify obstacles such as people, furniture, walls, or other objects. The detected obstacles are analyzed to estimate their position relative to the user and determine whether they obstruct the path. Based on this analysis, the software generates haptic feedback through vibration motors, where different vibration patterns or intensities indicate the direction and proximity of the obstacle. This allows the user to navigate safely without relying on visual information. Since the system uses only a webcam, it is cost-effective, portable, and easy to deploy while providing real-time obstacle detection and tactile guidance for applications such as assistive navigation for visually impaired individuals.
